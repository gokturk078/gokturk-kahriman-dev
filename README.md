# Göktürk Kahriman — Portfolio Website

The source for Göktürk Kahriman's personal software and AI portfolio website.

**Status:** Deployed supporting portfolio site.  
**Live site:** [gokturk-kahriman-dev.vercel.app](https://gokturk-kahriman-dev.vercel.app/)

## Purpose

The site provides a concise public route to selected project work, services, background, and contact information. It is a navigation and presentation layer rather than a flagship engineering system.

## Technology

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion

## Local Development

```bash
npm install
npm run dev
```

Production builds use `npm run build` and are emitted to Vite's `dist` directory.
